# 幸运硬币项目结构文档

## 项目概述
这是一个基于Godot引擎开发的推币机游戏项目，名为"幸运硬币"。游戏采用模块化架构，包含多个系统来管理游戏的不同方面，如经济系统、压力系统、债务系统等。

## 项目结构

### 📁 根目录结构
```
lucky-coin/project/
├── assets/           # 游戏资源文件
```

- 管理全局游戏状态（回合、压力、金钱等）

## 🎮 游戏核心机制

### 1. 经济系统
- **双货币制**: 正常金钱 + 贷款金钱
- **债务目标**: 6个回合需要偿还特定金额的债务
- **银行系统**: 存款生息、贷款功能

### 2. 压力系统
- **压力值**: 0-100，影响游戏视觉效果
- **压力来源**: 推币机操作、债务压力等
- **压力效果**: 视觉扭曲、滤镜效果

### 3. 硬币系统
- **6种硬币类型**: 真硬币、太阳币、月亮币、星星币、骷髅币、血币
- **双面硬币**: 部分硬币有高价值面和低价值面
- **硬币分布**: 每个通道有不同的硬币组成

### 4. 图案系统
- **基础图案**: 三连、四连、五连
- **特殊图案**: 箭头、眼、日、全屏
- **图案奖励**: 不同图案有不同的倍率和压力减少效果

### 5. 道具系统
- **永久道具**: 持续生效的增益道具
- **消耗道具**: 一次性使用的道具
- **充能道具**: 需要冷却时间的道具
- **限次道具**: 有使用次数限制的道具

### 6. 事件系统
- **随机事件**: 每回合可能触发的事件
- **事件类型**: 图案概率、价值、压力、银行、道具
- **事件效果**: 永久改变游戏机制

## 🎯 游戏目标

玩家需要在6个大回合内，通过推币机操作获得足够的金钱来偿还债务：
- 第1回合: 66元
- 第2回合: 200元  
- 第3回合: 666元
- 第4回合: 2222元
- 第5回合: 6666元
- 第6回合: 14444元

成功偿还所有债务即可获得游戏胜利！

## 🔧 技术架构

### 设计模式
- **单例模式**: Global.gd作为全局状态管理器
- **观察者模式**: 通过信号系统实现组件间通信
- **模块化设计**: 各系统独立运行，通过接口交互

### 数据流
1. **配置加载**: 从JSON文件加载游戏配置
2. **系统初始化**: GameManager初始化各个子系统
3. **状态同步**: 通过信号系统保持状态一致性
4. **UI更新**: 各视图监听状态变化并更新显示

### 扩展性
- **新硬币类型**: 在coin_types.json中添加配置
- **新图案**: 在pattern_config.json中定义
- **新道具**: 在shop_items.json中配置
- **新事件**: 在events_config.json中添加

这个项目展现了一个完整的游戏系统架构，具有良好的模块化设计和扩展性。
